# 축구 커리어 시뮬레이터 (fo_car)

16세 유망주로 시작해 은퇴까지 개인 커리어를 이어가는 웹 기반 축구 시뮬레이션 게임입니다.

- **1단계**: 데이터 스키마, OVR 산출, 턴 시뮬레이션 코어
- **2단계**: 턴 사이 진행(훈련·상점·사건), 이적·오퍼·경쟁 선수, 시즌 결산(시상·승강·기록·레전드·파트너·라이벌).
  브라우저에서 **16세 데뷔부터 은퇴까지 클릭만으로 플레이할 수 있습니다.**
- **3단계**: 득점·발롱도르 밸런스 재조정(포지션별 수상 가능성), 외부 구단 DB 자동 병합 파이프라인과 47개 리그 슬롯,
  바둑돌 하이라이트 연출(패스 궤적·골망·태클·선방), 상황별 아바타 의상(국가대표 유니폼·시상식 턱시도+트로피),
  커뮤니티 공유용 커리어 요약·텍스트 복사.
- **4단계**: 엑셀 구단 DB(**47개 리그 · 801개 구단**, 2025/26 실적·유니폼 색·레전드) 적용, 이적 오퍼의 권역 2단계 선택,
  UI 리디자인 — **차분한 다크 톤 + 민트 포인트**, 읽기 쉬운 시스템 폰트와 둥근 카드·입력창,
  **3등신 도트 전신 캐릭터**(유니폼은 DB의 구단 색)와 절제된 선수 미리보기,
  **한 화면 대시보드**(PC 16:9 · 휴대폰 세로 9:16)와 **경기 → 사건 → 훈련 → 상점 → 이적 자동 진행**, 상점 3개 진열,
  **숨은 포텐셜과 매 턴 자연 성장**.
- **5단계 (현재)**: 코치와 대화하는 4단계 선수 생성, 주발·약발 숙련도, 포지션별 턴 결과 리포트,
  실제 출전하는 중요 경기에서만 턴당 무작위 0~2회 선택, 초기 역할과 플레이 계산 분리, 확률적 포지션 변경 제의.

## 실행

```bash
npm ci            # 의존성 설치
npm run dev       # http://localhost:3000 → 커리어 게임 / http://localhost:3000/sandbox → 엔진 샌드박스 + 구단 DB 현황
npm test          # Vitest (152개)
npm run db:import -- 구단DB.xlsx   # 엑셀 구단 DB → data/external/club-db.json
npm run db:sync   # data/external/ 외부 구단 JSON 색인 갱신 + 병합 보고서 (dev·build·test·sim 전에 자동 실행)
npm run sim       # 시즌 단위 밸런스 점검 (SEEDS=100 npm run sim)
npm run sim:career  # 16세~은퇴 풀 커리어 자동 시뮬레이션 (CAREERS=30 ONLY=poacher,stopper DETAIL=0)
npm run sim:growth  # 성장 곡선 점검: 숨은 포텐셜에 몇 살에 닿는지 (CAREERS=10 SEED0=1)
npm run sim:ballon  # 발롱도르 점수 보정표 (기준 시즌별 1위·포디움 확률)
npm run typecheck && npm run lint
```

> npm 10.9에서 `npm install <패키지>` 시 `Cannot read properties of null (reading 'edgesOut')` 오류가 나면
> `--legacy-peer-deps`를 붙여 설치하세요 (npm 자체 버그). `npm ci`는 영향이 없습니다.

기술 스택: Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS 4 · Zustand 5 (LocalStorage 세이브) · Vitest

## 플레이 방법

1. **캐릭터 생성**: 코치가 이름·국적 → 포지션·초기 역할·주발·신체 조건 → 시작 리그·구단 → 외모 순서로 질문합니다. 이전 단계로 돌아가도 입력은 유지됩니다. 세부 역할은 시작 능력치 분배에만 쓰이고, 이후 플레이에서는 현재 포지션 공통 프로필을 사용합니다.
2. **한 턴의 흐름** — 위쪽 단계 표시 `① 경기 → ② 사건 → ③ 훈련 → ④ 상점 → ⑤ 이적` 순서로 진행합니다.
   선택을 하면 다음 단계로 **자동으로 넘어가고**, 할 일이 없는 단계(사건 없음 · 살 수 있는 물건 없음 · 받은 오퍼 없음)는 건너뜁니다.
   단계 표시를 눌러 언제든 앞뒤로 옮겨 갈 수 있고, 방금 한 선택의 결과는 다음 단계 위에 잠깐 표시됩니다.
   - **① 경기**: 전반기·후반기·프리시즌 중 한 턴을 시뮬레이션합니다. 하이라이트 선택은 턴당 무작위 0~2회입니다. 실제 출전하는 컵 결승·더비/라이벌전·리그 우승 결정전만 대상으로 삼고, 일반 빅매치·친선경기로 대체하지 않습니다. 같은 시드와 턴은 같은 횟수·상황을 재현합니다. "AI에게 맡기기"로 건너뛸 수도 있습니다.
   - **② 사건**: 턴마다 1~3개를 하나씩 보여 줍니다. 선택지마다 능력치·멘탈·명성·자산·체력이 달라지고, 모두 답해야 다음 경기를 할 수 있습니다.
   - **③ 훈련**: 세부 능력치 2~3개 · 영역 1개 · 벌크업 · 감량 · 휴식 중 하나, 강도(가볍게/보통/강하게). 턴당 1회.
   - **④ 상점**: 매 턴 **지금 잔고로 살 수 있는 물건 중 무작위 3개**가 진열되고, 그중 1개를 살 수 있습니다 (31세부터는 노화 방어).
   - **⑤ 이적**: 받은 오퍼(완전 이적·임대·재계약)를 수락·거절합니다. 오퍼마다 같은 포지션 경쟁 선수 요약이 붙고, 직접 협상에서 역제의(턴당 3회)·재계약 요청을 할 수 있습니다.
3. **화면**: PC는 16:9 한 화면에 왼쪽 선수 카드 · 가운데 지금 단계 · 오른쪽 **턴 성적**(출전 · 골 · 도움 · 평점 큰 숫자, 팀 성적 · 순위 변화, 하이라이트 결과)과 **턴별 기록 표** · 소식이 함께 나옵니다.
   휴대폰 세로 화면은 선수 한 줄 · 지난 턴 성적 한 줄 · 단계 표시 · 지금 단계로 한 화면에 들어가고, 성적 한 줄을 누르면 자세한 성적과 턴별 기록을 봅니다.
   선수 세부 능력치와 기록실은 창으로 엽니다.
4. **결산**: 리그 시상식(후반기 후)과 세계 시상식(프리시즌 후)은 모달로, 기록 경신·레전드 헌액·이적·승격 같은 소식은 팝업으로 뜹니다.
5. **은퇴**: 30세부터 직접 은퇴할 수 있고, 40세가 되거나 33세 이상에서 FA로 6턴을 보내면 자동으로 은퇴합니다. 은퇴하면 커리어 요약 화면이 나옵니다.
6. **공유**: 은퇴 화면과 기록실 탭의 "커리어 요약 · 공유" 카드에서 시즌별 기록을 한눈에 보고, **클립보드에 텍스트 복사**로 커뮤니티에 붙여 넣을 수 있습니다.

"자동 1턴"과 "자동 1시즌" 버튼은 AI가 훈련·구매·사건·이적을 대신 결정해 진행합니다.
진행 상황(하이라이트 도중 포함)은 LocalStorage에 자동 저장되어, 새로고침해도 이어서 플레이할 수 있습니다.

## 커리어 루프

```
createCareer
  └─▶ READY (턴 사이: 훈련 · 상점 · 사건 · 이적)
        └─ startTurn ─▶ (하이라이트 대기) ─ continueTurn(바둑돌 결과) ─▶ completeTurn
              1. 턴 결과 반영: 입지 · 연봉 · 경기 경험 성장 · 통산 기록 · 파트너/라이벌 관계
              2. A매치 기간 (국가대표 차출 시)
              3. 기록 경신 판정 → 팝업
              4. 파트너 · 라이벌 생성/이탈
              5. 후반기 뒤 → closeLeagueSeason  (리그 시상 · 승강 · 구단 실력/명성/재정 갱신)
                 프리시즌 뒤 → closeSeasonCycle (세계 시상 · 시즌 기록 · 노화 · 경쟁 선수 순환 · 다음 시즌)
              6. 오퍼 생성 → beginInterTurn (회복 · 사건 1~3개) ─▶ READY
  ... 반복 ... ─▶ retire ─▶ RETIRED (커리어 요약 · 레전드 헌액)
```

- 연 3턴, 추춘제: `2026/27 전반기 → 후반기 → 프리시즌(대표팀 여름 대회) → 2027/28 전반기 …`
- 계약은 마지막 시즌 후반기가 끝나고 프리시즌에 들어갈 때 만료됩니다. 만료 전 턴에는 재계약 오퍼가 오고, 만료되면 FA로 최대 5개의 오퍼를 받습니다.
- 모든 무작위성은 `(시드, 대상 id, 용도)`로 나눈 독립 난수 스트림을 씁니다. 같은 세이브에서 같은 선택을 하면 결과가 같습니다.

## 2단계 규칙 요약

### 턴 사이 진행 (`engine/interTurn.ts` · `growth.ts` · `shop.ts` · `events.ts`)
| 항목 | 규칙 |
| --- | --- |
| 자연 회복 | 겨울 휴식기 +15, 시즌 종료 후 +20, 개막 전 +25 |
| 카테고리 훈련 | 6대 영역 중 1개 → 그 영역의 세부 3개 각각 기대 +1.15 |
| 세부 훈련 | 2개 고르면 개당 +2.1, 3개면 개당 +1.6 (집중할수록 크게) |
| 벌크업 / 감량 | 몸무게 ±(1.0~2.6kg). 벌크업은 몸싸움·공중볼↑ 가속·민첩↓, 감량은 그 반대 (BMI가 극단이면 체력 −0.5) |
| 강도 | 가볍게 ×0.6 (체력 −6) / 보통 ×1.0 (−12) / 강하게 ×1.4 (−20, 멘탈 −2), 휴식은 체력 +22 · 멘탈 +3 |
| 효율 보정 | 나이(18세 1.0 → 30세 0.25 → 34세 0.05) × 현재 수치(포텐셜에 비해 높을수록 덜 오름) × 포텐셜 근접 보정 × 확률적 반올림 |
| 상점 | 턴당 1개 · 세부 능력치 1개 · **진열은 잔고로 살 수 있는 물건 중 무작위 3개**(턴마다 고정). **효과 = min(나이 보정 효과, 같은 능력치를 그 턴에 훈련했을 때의 기대 상승)** → 최고가 아이템도 훈련 1회를 넘지 않음. 20세까지 100%, 이후 나이에 반비례 |
| 노화 방어 | 31세부터 아이템은 상승 대신 "다음 시즌 노화 감소를 막는 방어막"이 됨 |
| 노화 | 30세부터 속도 → 지구력 → 힘·기술 → 판단형 능력치(결정력·시야·수비 위치 등) 순으로 감소. GK는 3년 늦게 시작 |
| 사건 | 턴마다 1~3개 (확률 45/35/20%). 가정사 · 언론 · 훈련 방식 · 스폰서 · 팀 · 파트너 · 라이벌 |
| **체력 100 규칙** | 후반기 뒤 '휴가 계획' 사건에서 **휴식**을 고르고 **그해 여름 대표팀 차출이 없으면** → 다음 시즌을 체력 100으로 시작 (`seasonStartCondition`) |

### 이적 (`engine/transfer.ts`)
- **개수 먼저, 조건은 나중에**: 오퍼 수는 0/1/2/3개(확률 40/30/20/10%), FA는 최대 5개로 먼저 정합니다. 그다음 내 OVR·명성·나이와 구단의 실력·명성·재정·지역성으로 구단을 고르고 조건을 정합니다.
- **조건**: 연봉 = 25,000 × e^(재정 × 0.06) × 역할 계수 × 명성 계수. 사우디·MLS 같은 자본 리그는 ×1.5. 재계약은 `max(시장 목표치, min(현 연봉 × 1.05, 시장가 × 1.3))`. 이적료 = 시장 가치 × 역할 계수 × (0.6 + 0.2 × 남은 계약 연수(최대 2)).
- **유형**: 완전 이적 / 임대(23세 이하, 최소 로테이션 보장, 1시즌) / 재계약 (계약 마지막 시즌, 또는 요청 시)
- **역제의**: 턴당 3회. 구단·유형(이적/임대)·희망 출전 시간을 지정하면 구단의 관심도에 따라 수락 여부가 정해지고, 수락되면 오퍼 목록에 추가됩니다. 재계약 요청은 별도로 할 수 있습니다.
- **경쟁 선수**: 오퍼마다 그 팀의 같은 포지션 경쟁자 0~3명(이름·나이·OVR·입지)을 보여 줍니다. 경쟁자는 시즌마다 나이를 먹고 성장·노화하며, 이적·은퇴·신규 영입으로 바뀝니다.

### 시즌 결산 (`engine/seasonEnd.ts` · `awards.ts` · `records.ts` · `narrative.ts`)
- **리그 시상** (후반기 후): 득점왕 · 도움왕 · MVP · 베스트 11 (포지션 부문)
- **세계 시상** (프리시즌 후): 발롱도르(30위까지 순위) · FIFA 올해의 선수(3위까지) · 월드 베스트 11 · 대륙 올해의 선수 · 국가 올해의 선수.
  리그 수준에 따른 인지도 보정(`leagueRecognition`)이 들어가 약한 리그에서 발롱도르를 받기는 어렵습니다. 점수 공식은 아래 '3단계 변경 요약' 참고.
- **승강**: EPL↔챔피언십 3팀, 라리가↔라리가2 3팀, K리그1↔K리그2 1팀 (B팀은 승격 불가)
- **구단 수치**: 성적이 기대 순위보다 좋으면 명성이 오르고, 우승 +2.5, 승격 +3, 강등 −6입니다. 실력은 `50 + 명성×0.4 + (재정−명성)×0.08`을 향해 매년 최대 ±2씩 움직입니다.
- **기록 경신**: 구단·리그·국가대표 통산 득점/도움/출전 기록을 넘으면, 기존 보유자 이름이 담긴 팝업이 뜹니다 (`data/legends.ts`의 `HISTORIC_RECORDS`).
- **레전드 헌액**: 한 구단에서 오래 뛰며 큰 기록을 남기고 떠나거나 은퇴하면 헌액됩니다. 같은 포지션의 실존 레전드가 데이터에 있으면 언급하고, 없으면 생략합니다.
- **파트너 · 라이벌**: 주전으로 3턴 이상 뛰면 확률적으로 생깁니다. 파트너는 같은 팀의 호흡 맞는 동료(투톱·센터백 듀오 등), 라이벌은 더비 상대·우승 경쟁 팀·세계적 스타 중에서 나옵니다. 매 턴 결과 화면에 기록을 나란히 비교해 보여 주고, 하이라이트에서 상대 팀에 있으면 이름표로 표시합니다.

## 3단계 변경 요약

### 득점 밸런스 (`engine/simulator.ts` · `data/playstyles.ts`)
- 득점·도움 점유율 상한을 **완만하게 눌러 주는 방식**(`softCap`)으로 바꿨습니다. 상한의 60%까지는 그대로, 그 위는 상한에 점점 가까워지기만 합니다.
- **득점 상한은 팀 수준에 따라 오릅니다**: 팀 실력 70 이하 0.27 → 90 이상 0.37. 빅클럽 에이스는 시즌 30~45골을 넣고,
  약팀에서 혼자 몰아치는 기록은 덜 부풀려집니다.
- 스타일별 기본 점유율을 낮췄습니다(포처 0.30→0.25, 플레이메이커 도움 0.24→0.16, 스토퍼 득점 0.035→0.017 등).
- **키패스** 기록을 새로 집계합니다(기대 도움 ÷ 전환율 0.16). 도움이 되지 않은 키패스는 평점(+0.1)과 명성에 반영되고, 미드필더 시상 평가에 쓰입니다.
- **미드필더 평점 보정**: 골·클린시트 보너스가 없는 미드필더가 공격수·수비수보다 평점이 체계적으로 낮았습니다(정상급 6.9~7.1).
  팀 수준을 웃도는 미드필더는 경기 장악(관여도)이 평점에 1.7배 반영되어 정상급이 7.2~7.4가 됩니다.
- **스타일 간 성장 속도 보정** (`engine/growth.ts`): OVR 가중치가 여러 능력치에 퍼진 스타일(박스 투 박스·인사이드 포워드)은
  같은 훈련으로도 OVR이 덜 올라 최고 OVR이 5~7 낮았습니다. 훈련 효율(상위 2개 가중치 비중 기준, 0.85~1.6배)과
  경험·자연 성장 배분을 정규화해 차이를 2~4로 줄였습니다(골키퍼는 노화가 늦어 조금 높습니다).

### 숨은 포텐셜 · 매 턴 자연 성장 (`engine/growth.ts`)
- 필드 선수의 포텐셜은 **80~100**, 성장 한도는 **18개 필드 능력치의 가중치 없는 평균**으로 판정합니다. GK 능력치와 약발 숙련도는 이 평균에서 제외하며, 반올림하지 않습니다.
- GK는 기존 **80~100 / 포지션 OVR 기준**을 유지합니다. 기존 포텐셜은 재추첨하지 않고 80 미만인 옛 세이브만 80으로 보정합니다.
- 낮은 값이 흔한 기존 볼츠만 분포(temperature=5)는 유지합니다. 포텐셜까지 3 이내로 가까워지면 훈련·경험·자연 성장·아이템 효과를 줄입니다. 개별 능력치 상한 99는 그대로입니다.
- 필드 선수의 비주력 능력치도 평균 성장 한도를 향해 자연 성장합니다. GK의 개별 능력치 목표 방식은 유지합니다. 필드 선수의 연간 평균 성장 기대값은 `(포텐셜 - 현재 18개 능력치 평균) × 나이별 성장률 + 1`이며 출전·평점·컨디션으로 조정합니다. 나이별 성장률은 16세 18%, 19세 17%, 23세 16%, 27세 15%입니다. 잠재력에 가까워질수록 자연스럽게 둔화합니다. GK 성장식은 유지합니다. 필드 선수는 30~35세에 피지컬 하락분 일부를 기술·판단 능력에 재분배하며 연간 최대 3포인트와 평균 한도를 지킵니다.
- 현재 OVR·훈련·경기 기록·체력 소모는 초기 역할과 무관한 포지션 공통 프로필로 계산합니다. 초기 역할 선택은 초기 능력치 분배만 결정하며 플레이 화면·공유 문구에는 표시하지 않습니다.
- 다른 필드 포지션의 적합 OVR이 현재보다 3 이상 높으면 턴당 25% 확률로 포지션 변경 사건을 제의합니다. 수락 시 능력치·포텐셜을 유지하고 포지션과 OVR을 갱신합니다. 거절할 수도 있으며 GK 전환은 제의하지 않습니다.
- **시즌 중 즉시 성장**: 전반기·후반기·프리시즌의 모든 턴 완료 시 경기 경험과 자연 성장을 바로 적용합니다. 시즌이 끝날 때까지 기다리지 않습니다.
- [킥루의 공개 성장 가이드](https://kickru.com/guides/growth)에 나온 나이·출전·활약·컨디션 원칙을 참고해 자체 계수로 구현했습니다. 19세 미만은 기본 육성 성장을 받고, 성인 선수는 출전 시간이 많을수록 자연 성장과 경험 성장이 커집니다. 평점·평균 컨디션·시드에 고정된 선수별 성장 속도를 반영합니다.
- 유소년도 남은 잠재력 격차에 비례해 성장합니다. 한도 직전에도 연간 평균 +1의 기본 성장분을 더하며 실제 상승은 남은 평균 한도까지 제한합니다.
- 경기·자연 성장의 소수점은 `PlayerState.developmentCredits`에 누적하여 작은 상승분이 매 턴 사라지지 않게 합니다. 세이브와 복원 후에도 그대로 이어집니다.
- 턴 결과에는 **OVR 전후·능력치별 상승**을 표시하고 평균·중복 안내 문구는 생략합니다. 한도 도달과 성장치 누적 중 상태도 구분합니다. 시즌 마감 노화는 성장과 별도입니다.
- `npm run sim:growth`는 필드 선수는 18개 평균, GK는 OVR로 성장 한도 도달을 추적합니다.

### 주발 · 약발 · 턴 결과
- 주발은 왼발/오른발 중 선택합니다. 약발 숙련도는 0~100이며 40에서 시작합니다. 약발 훈련은 턴당 훈련 1회를 써서 숙련도 +3, 체력 -8을 적용합니다.
- 약발 숙련도가 높을수록 골·도움 기대값과 패스 성공률, 발로 처리하는 하이라이트 선택의 성공 확률이 높아집니다.
- 턴이 완료되면 리포트를 자동으로 열고, 리그 전체 순위·이번 턴 승무패·컵 대회 진행/탈락/우승·최근 경기 스코어를 보여줍니다. 선수 패널과 모바일 성적 줄에서 다시 열 수 있습니다.
- 개인 기록은 전체 대회 합산과 대회별로 함께 표시합니다. 공격수는 출전·골·도움·평점, 미드필더는 여기에 패스 성공률·키패스, 수비수는 성공 태클·클린시트, GK는 선방·클린시트를 강조합니다.
- 패스 성공률은 전체 성공 횟수 ÷ 전체 시도 횟수로 계산합니다. 태클과 패스는 경기 단위 시뮬레이션 기록으로 집계합니다. 구버전 세이브에서 없던 기록을 소급 생성하지 않습니다.
- 스트라이커 크로스 헤더·발리·포스트플레이·컷백, 미드필더 압박 탈출·침투 패스, 수비수 크로스 차단·역습 저지, GK 크로스 처리·일대일 등 포지션별 상황을 무작위로 보여줍니다. 상황은 실제 출전 시간 내에서 발생합니다.

### 엑셀 구단 DB 적용 (`scripts/import-club-db.ts` · `data/dbLoader.ts`)
- `npm run db:import -- 구단DB.xlsx`가 엑셀(구단 DB · 리그 목록 시트)을 `data/external/club-db.json`으로 바꿉니다. 열 대응표는 `data/external/README.md`.

- **첫 시즌**: 직전 시즌 순위·승강(직전 소속 리그)으로 리그 시작 순서를, '다음 대륙컵'으로 대륙 대회 진출을 정합니다.

- 테스트는 `FO_CAR_DB=sample`(vitest.config.mts)로 내장 샘플에 고정하고, `tests/full-db.test.ts`가 전체 DB(구단 수·색·레전드·득점 수준·커리어 완주)를 검사합니다.

### 이적 오퍼: 권역 2단계 선택
구단이 801개라 구단마다 가중치만 주면 먼 나라 구단 '수'가 이겨 울산 → 호주 → 아르헨티나 → 남아공 같은 경로가 나왔습니다.
이제 오퍼마다 **권역(같은 나라 · 인접국 · 같은 대륙 · 그 밖)을 먼저 정한 비율로 고르고**, 그 안에서 구단을 고릅니다.

| 선수 | 같은 나라 | 인접국 | 같은 대륙 | 그 밖 |
| --- | --- | --- | --- | --- |
| 유망주(21세 이하) · 무명 | 62% | 14% | 18% | 6% |
| 명성이 알려진 선수 (명성 35→70 보간) | 34% | 16% | 32% | 18% |
| 임대 | 78% | 10% | 10% | 2% |
| 스타 (명성 70+, 22세 이상) | 권역 제한 없음 | | | |

- 해외 권역은 후보 구단의 평균 리그 수준이 지금 리그보다 낮으면 비중이 줄고 높으면 늡니다(×0.25~1.5). 같은 대륙 안에서도 수준이 낮은 리그는 덜 고릅니다.
- 다른 대륙으로 갈 때는 수준 높은 리그를 선호하고(e^((리그 수준 − 62)/8)), 국적 국가 구단은 인접국 권역으로 봅니다.
- 완전 이적의 실력 적합도는 비대칭입니다(선수보다 약한 구단 σ 4.5 · 강한 구단 σ 7). 스타가 중위권 구단 '수'에 밀려 빅클럽 오퍼를 못 받던 문제를 줄였습니다.

## 유니폼 색 스키마 (`kitColors`) — 외부 구단 DB 연동용

```ts
// types/game.ts
export interface KitColors {
  primary: string;           // CSS 색 (예: '#DA291C')
  secondary: string | null;  // null → 단색, 값이 있으면 세로 줄무늬
  shorts?: string | null;    // 선택: 반바지 (없으면 상의 색을 어둡게)
  socks?: string | null;     // 선택: 양말 (없으면 상의 색)
}
ClubDefinition.kitColors: KitColors        // 필수
NationDefinition.kitColors?: KitColors     // 선택 (없으면 기본색)
```

- 도트 캐릭터(`components/pixel/sprite.ts`)는 `secondary`가 있으면 상의 몸통 10칸을 `primary · secondary · primary · secondary · primary`(2칸씩) 세로 줄무늬로 칠합니다.
- `data/clubs.ts`의 행 형식은 `[id, name, nameKo, shortName, power, prestige, finance, primary, secondary|null, rivals, options?]`이고, `defineLeague`가 `kitColors: { primary, secondary }`로 바꿔 줍니다.
- 외부 JSON은 `kitColors: { primary, secondary }`(또는 `colors: [p, s]`, `primaryColor`/`secondaryColor`)로 넣으면 되고, 빈 `secondary`는 로더가 `null`로 바꿉니다.
- 가로 줄무늬·하프 유니폼(예: QPR, 그라나다)은 지금은 대표색 단색으로 근사합니다.

## 핵심 설계

### 1. 정적 데이터와 동적 상태의 분리
`data/`의 `*Definition`은 변하지 않는 원본입니다. 시즌마다 변하는 구단 실력·명성·재정·소속 리그·스쿼드(경쟁 선수)는
`ClubState`로 `GameState`에만 저장합니다. 세이브 크기를 줄이고 데이터 패치를 쉽게 하기 위함입니다.

### 2. 능력치와 시뮬레이션 결과의 분리 원칙
| 결과 | 사용하는 값 | 함수 |
| --- | --- | --- |
| 팀 성적 (스코어·승무패) | 팀 실력, **내 OVR × 멘탈 계수** | `effectiveTeamPower` → `expectedGoals` → `simulateScore` |
| 개인 기록 (골·도움·클린시트·평점) | **세부 능력치 분배**, 멘탈 | `goalShare` · `assistShare` · `calculateMatchRating` |

경기마다 `(시드, 경기 id, 용도)`로 독립 난수 스트림을 만들기 때문에, OVR이 같은 두 선수는 결정력·시야 분배가
달라도 **팀 결과가 완전히 같고 개인 기록만 다릅니다** (`tests/simulator.test.ts`에서 검증).

### 3. 체력과 출전 경기 수
경기마다 체력이 소모되고 휴식일만큼 회복됩니다. 체력이 55 아래로 떨어지면 감독이 로테이션을 돌려
선발 확률이 줄어듭니다(큰 경기는 예외). 리그 강도·대륙 대회 주중 경기·포지션·지구력이 모두 반영되어,
**OVR이 높아도 지구력이 부족하면 시즌 전 경기를 소화하지 못합니다.**

### 4. 턴 세션과 하이라이트 경기
- 세션은 순수 데이터라 하이라이트 대기 중에도 LocalStorage에 저장·복원됩니다.
- 하이라이트 경기는 턴을 선택지 없이 한 번 미리 돌려 본 뒤 규칙에 맞게 고릅니다.
  - 전반기: 라이벌 더비 (없으면 빅매치) / 후반기: 대륙컵 결승 > 국내컵 결승 > 후반기 더비
  - 프리시즌: 대표팀이 치른 마지막 국제대회 경기 > 연습경기 / B팀·유스: 리저브 더비
- 바둑돌 피치에서 상황(슈팅·키패스·드리블·수비·선방·세트피스)마다 선택지 3개가 나옵니다.
  성공률 = 시그모이드((선택지 핵심 능력치 − 상황 난이도)/12) × 멘탈 보정 (5~95%).
  결과는 득실점·골·도움·평점·멘탈로 바뀌고, 남은 경기에도 영향을 줍니다.

## 핵심 수식 요약 (`engine/simulator.ts` · `SIM_CONFIG`)

| 항목 | 수식 |
| --- | --- |
| OVR | Σ(스탯 × 가중치) / Σ가중치 — 플레이스타일별 `ovrWeights` |
| 멘탈 계수 | 0.9 + 0.2 × 멘탈/100 |
| 주인공 출전 시 팀 실력 | 구단 실력 + 0.12 × (OVR × 멘탈 계수 − 구단 실력) × 출전 비율 (GK 0.10) |
| 기대 득점 | 1.35 × e^(0.045 × (내 실력 + 홈 2.5 + 컨디션 노이즈 − 상대 실력)) → 포아송 |
| 득점 점유율 | softCap(스타일 기본값 × clamp(e^((득점 프로필 − 팀 수준)/22), 0.3, 1.8) × 멘탈 보정, 상한) · 상한 = 0.27 + 0.10 × (팀 실력 70→90) |
| 키패스 | 도움 + 포아송(기대 도움 × (1/0.16 − 1)) |
| 평점 | 6.45 + 관여도 + 골·도움 + 팀 결과 + 수비 기여(클린시트·실점·선방) + 멘탈 + 노이즈 |
| 체력 소모(90분) | 7 × 리그 강도 × 포지션·스타일 배율 × (1.4 − 0.7 × 지구력/100) |
| 체력 회복(1일) | 0.45 + 0.6 × 지구력/100 |
| 초기 능력치 | 기본 34 + 스타일 가중치 비례 최대 +24 + 키·BMI 보정 + 노이즈 (16세 OVR ≈ 50~55) |
| 시작 입지 | OVR − 팀 실력 ≥ −3 → 1군 / ≥ −12 → B팀 / 그 외 → U19 |

## 단순화한 부분 · 알려진 한계
- 토너먼트는 단판, 대륙 대회 조별리그는 4팀 더블 라운드로빈으로 근사합니다.
- 대륙 대회·국내컵 상대가 데이터에 부족하면 가상 팀(하부리그·대륙 클럽)으로 채웁니다.
- 47개 리그 801개 구단은 엑셀 DB(2025/26 실적) 기준입니다. 잉글랜드 3~4부처럼 슬롯에 없는 하부 리그는 국내 컵의 가상 하부 팀으로만 존재합니다.
- 엑셀에는 상의 색(제1색·줄무늬 제2색)만 있어 반바지·양말 색은 추정합니다. 가로 줄무늬·하프 유니폼은 대표색으로 근사합니다.
- 김천 상무처럼 실제로는 영입이 제한된 구단도 일반 구단처럼 오퍼를 냅니다.
- 자동 진행 AI의 미드필더 커리어는 최고 OVR 82~86에서 멈추는 경우가 많아, UCL 우승권 구단에 자리 잡지 못하고 포디움 근처(3~8위)에 머뭅니다.
  시상 공식 자체는 UCL 더블을 이끈 플레이메이커에게 1위 53%를 주도록 보정되어 있습니다.
- NPC 경쟁 선수·시상 후보는 이름·나이·OVR·포지션만 가진 가벼운 모델입니다(세부 능력치 없음).
- 세이브 버전이 바뀌면(`SAVE_VERSION`) 이전 세이브는 초기화됩니다. 키패스 도입 전 세이브는 그대로 이어서 플레이할 수 있습니다(키패스 0부터 집계).


### 초기 재능 · 간결한 진행 화면
- 초기 OVR은 40~70이며 50이 최빈값인 볼츠만 분포로 독립 추첨합니다 (`E=(OVR-50)^2`, `T=98`). 초기 역할·체격에 따른 능력치 분배를 유지하며 실제 OVR이 추첨값과 일치하도록 맞춥니다. 생성 화면에서는 OVR과 추첨 전 입지를 미리 보여주지 않습니다.
- 훈련의 영역 탭을 제거했습니다. 카테고리 제목을 누르면 그 영역 전체가 선택되고, 개별 능력치를 누르면 직접 고를 수 있습니다.
- 상점은 이전 구매 물건도 다시 진열합니다. 턴당 한 개 제한은 유지하고 효과는 정성적으로만 표시합니다. 구매 이력은 같은 물건끼리 묶습니다.
- 입원 사건은 가중치 0.4, 최소 12턴 간격, 커리어 최대 두 번입니다. 발생 기록은 저장·복원 후에도 유지됩니다.
- 대시보드는 읽기 편한 두 열 구조로, 턴 결과는 핵심 성적과 성장부터 보여줍니다. 대회별 성적·전체 순위표는 펼쳐 볼 수 있습니다.


### 2등신 선수와 140종 사건
- 캐릭터를 큰 머리·작은 몸·짧은 팔다리와 한 픽셀 외곽선의 24×32 도트로 다시 그렸습니다. 피부·머리·눈 색, 구단/국가대표 유니폼, 턱시도·트로피를 유지합니다.
- 사건은 28종에서 140종으로 확장했습니다. 112개의 본문·선택지를 개별 작성했으며 유소년 생활, 실력 향상, 주전 경쟁, 가족, 언론, 스폰서, 파트너·라이벌, 전성기와 베테랑 사건을 포함합니다.
- 나이와 명성뿐 아니라 현재 OVR의 최소·최대 조건 및 포지션 조건으로 해금합니다. 스타 전용 행사는 어린 신인에게 나타나지 않습니다.
- 일반 사건은 최소 6턴 간격이며 단발성 인생 사건은 한 번만 발생합니다. 여러 사건이 뽑히는 턴에는 다른 카테고리를 우선하고, 이미 자주 본 사건의 추첨 가중치는 낮춥니다. 필수 휴가와 입원 사건의 별도 제한은 유지합니다.


### OVR 집중 정책의 50회 성장 감사
- `npm run sim:audit-growth`로 독립 시드 1~50을 ST/CM/CB/LW/AM 각 10명에 배분해 비교합니다. `CAREERS`, `AUDIT_OUTPUT` 환경변수로 횟수와 원본 JSON 경로를 지정할 수 있습니다.
- 사건의 기대 OVR 효과, 핵심 2/3개·영역·벌크업·감량·휴식 훈련, 진열된 구매 가능 아이템을 비교합니다. 출전을 위해 체력 55 이상을 유지하고, 더 높은 OVR의 포지션 제의를 수락합니다. 이적·재계약과 하이라이트는 기존 자동 정책을 사용하며 미래 난수나 세이브 반복은 사용하지 않습니다.
- 훈련 전후와 경기 종료 후를 모두 관측합니다. 정수 OVR 최고치를 처음 기록한 나이, 최종 최고 OVR의 95% 도달 나이, 필드 평균이 포텐셜까지 1 이내인 나이와 실제 한도 도달 나이를 따로 집계합니다.
- 50회 수정 전 감사에서 OVR 고점 중앙값은 23세, 풀포텐셜 도달 중앙값은 22세였습니다. 50명 모두 21세까지 최종 OVR의 95%를 넘었습니다.
- 필드 자연 성장률을 재조정하고 집중 훈련 효율을 기존의 60%로 조정했습니다. 자연 성장의 핵심 능력치 쏠림도 줄여 완성이 너무 빨라지는 중첩을 낮춥니다. +1 기본 성장분, 매 턴 성장, 평균 한도와 베테랑 재분배는 유지하며 GK 성장률과 훈련 효율은 바꾸지 않습니다.

- 같은 50개 시드 재검증: OVR 고점 중앙값 **23→27세**, 21세 이하 조기 고점 **20→0명**, 25~29세 고점 **18→42명**, 풀포텐셜 중앙값 **22→27세**. [50회 비교 결과](docs/growth-audit-50.md)와 행별 CSV를 제공합니다.


### 세계 시상 후보의 리그 수준과 메이저 대회 기여
- NPC 발롱도르 후보는 소속 리그를 먼저 정하고 그 수준으로 점수를 보정합니다. 최상위 유럽 5개 1부 리그를 중심으로 후보를 뽑으며 비유럽·비최상위·2부 구단은 높은 구단 전력만으로 같은 세계 최상위 점수를 받지 않습니다. 현재의 동적 소속 리그를 사용해 승강도 반영합니다.
- 실제 소속 리그가 있는 플레이어도 같은 리그 보정을 사용합니다. 비최상위 리그 선수를 배제하지 않으며 국가대표 활약·월드컵 성과로 경쟁할 여지는 유지합니다.
- UCL 우승 기본 점수는 14→16, 월드컵은 20→22로 소폭 높였습니다. 실제 우승팀에서의 해당 대회 선발·출전 시간 비중에 따라 추가로 UCL 최대 2점, 월드컵 최대 3점을 받습니다. 리그 주전 기록을 대신 쓰지 않으며 미출전·준우승·이적 전 다른 구단의 기록은 주축 가산 근거가 되지 않습니다.
- 실제 외부 DB에서 파우메이라스·알힐랄의 전력을 90으로 올린 1,000개 후보 풀을 검사했습니다. NPC 1위는 모두 최상위 5개 리그에서 나왔고, 비최상위 후보도 1,526명 포함되어 완전히 배제되지는 않았습니다. 기준 레알 트레블 시즌보다 높은 비최상위 후보는 0명이었습니다.
