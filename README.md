# 축구 커리어 시뮬레이터 (fo_car)

16세 유망주로 시작해 은퇴까지 개인 커리어를 이어가는 웹 기반 축구 시뮬레이션 게임입니다.
현재는 **1단계: 데이터 스키마 + OVR 산출 + 턴 시뮬레이션 코어** 프로토타입까지 구현되어 있습니다.

## 실행

```bash
npm ci            # 의존성 설치
npm run dev       # 개발 서버 → http://localhost:3000 (엔진 샌드박스 화면)
npm test          # Vitest
npm run sim       # 밸런스 점검용 시즌 시뮬레이션 (SEEDS=100 npm run sim)
npm run typecheck && npm run lint
```

> npm 10.9에서 `npm install <패키지>` 시 `Cannot read properties of null (reading 'edgesOut')` 오류가 나면
> `--legacy-peer-deps`를 붙여 설치하세요 (npm 자체 버그). `npm ci`는 영향이 없습니다.

기술 스택: Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS 4 · Zustand 5 · Vitest

## 핵심 설계

### 1. 정적 데이터와 동적 상태의 분리
`data/`의 `*Definition`은 변하지 않는 원본이고, 시즌마다 변하는 구단 실력·명성·재정·소속 리그는
`ClubState`로 `GameState`에만 저장합니다. 세이브 크기를 줄이고 데이터 패치를 쉽게 하기 위함입니다.

### 2. 능력치와 시뮬레이션 결과의 분리 원칙
| 결과 | 사용하는 값 | 함수 |
| --- | --- | --- |
| 팀 성적 (스코어·승무패) | 팀 실력, **내 OVR × 멘탈 계수** | `effectiveTeamPower` → `expectedGoals` → `simulateScore` |
| 개인 기록 (골·도움·클린시트·평점) | **세부 능력치 분배**, 멘탈 | `goalShare` · `assistShare` · `calculateMatchRating` |

경기마다 `(시드, 경기 id, 용도)`로 독립 난수 스트림을 만들기 때문에, OVR이 같은 두 선수는 결정력·시야 분배가
달라도 **팀 결과가 완전히 같고 개인 기록만 다릅니다** (`tests/simulator.test.ts`에서 검증).

### 3. 체력과 출전 경기 수
경기마다 체력이 소모되고 휴식일만큼 회복됩니다. 체력이 55 아래로 떨어지면 감독이 로테이션을 돌려
선발 확률이 줄어듭니다(큰 경기는 예외). 리그 강도·대륙 대회 주중 경기·포지션·지구력이 모두 반영되어,
**OVR이 높아도 지구력이 부족하면 시즌 전 경기를 소화하지 못합니다.**

### 4. 턴 세션과 하이라이트 경기
```
createTurnSession → advanceTurn ─(하이라이트 직전 정지)→ resolveHighlight(바둑돌 결과) → advanceTurn → finalizeTurn
```
- 세션은 순수 데이터라 하이라이트 대기 중에도 LocalStorage에 저장·복원됩니다.
- 하이라이트 경기는 턴을 선택지 없이 한 번 미리 돌려 본 뒤 규칙에 맞게 고릅니다.
  경기별 독립 시드 덕분에 하이라이트 이전까지는 실제 진행과 결과가 같습니다.
  - 전반기: 라이벌 더비 (없으면 빅매치)
  - 후반기: 대륙컵 결승 > 국내컵 결승 > 후반기 더비
  - 프리시즌: 대표팀이 치른 마지막 국제대회 경기 > 연습경기
  - B팀·유스: 리저브 더비
- 선택지 결과는 득실점·골·도움·평점으로 바뀌고, 멘탈은 즉시 반영되어 남은 경기에 영향을 줍니다.
  명성 보너스와 (연습경기라면) 다음 시즌 입지 점수에도 반영됩니다.
- 라이벌·옛 파트너가 상대 팀에 있으면 브리핑의 바둑돌 목록에 이름이 표시됩니다.

## 핵심 수식 요약 (`engine/simulator.ts` · `SIM_CONFIG`)

| 항목 | 수식 |
| --- | --- |
| OVR | Σ(스탯 × 가중치) / Σ가중치 — 플레이스타일별 `ovrWeights` |
| 멘탈 계수 | 0.9 + 0.2 × 멘탈/100 |
| 주인공 출전 시 팀 실력 | 구단 실력 + 0.12 × (OVR × 멘탈 계수 − 구단 실력) × 출전 비율 (GK 0.10) |
| 기대 득점 | 1.35 × e^(0.045 × (내 실력 + 홈 2.5 + 컨디션 노이즈 − 상대 실력)) → 포아송 |
| 득점 점유율 | 스타일 기본값 × e^((득점 프로필 − 팀 수준)/18) × 멘탈 보정, 최대 45% |
| 평점 | 6.45 + 관여도 + 골·도움 + 팀 결과 + 수비 기여(클린시트·실점·선방) + 멘탈 + 노이즈 |
| 체력 소모(90분) | 7 × 리그 강도 × 포지션·스타일 배율 × (1.4 − 0.7 × 지구력/100) |
| 체력 회복(1일) | 0.45 + 0.6 × 지구력/100 |
| 선택지 성공률 | 시그모이드((핵심 능력치 − 난이도)/12) × 멘탈 보정, 5~95% |
| 초기 능력치 | 기본 34 + 스타일 가중치 비례 최대 +24 + 키·BMI 보정 + 노이즈 (16세 OVR ≈ 50~55) |
| 시작 입지 | OVR − 팀 실력 ≥ −3 → 1군 / ≥ −12 → B팀 / 그 외 → U19 |

## 프로토타입 단순화 (추후 확장)
- 토너먼트는 단판, 대륙 대회 조별리그는 4팀 더블 라운드로빈으로 근사합니다.
- 대륙 대회·국내컵 상대가 데이터에 부족하면 가상 팀(하부리그·대륙 클럽)으로 채웁니다.
- 첫 시즌 대륙 대회 진출권은 실력 순위를 직전 시즌 순위로 간주해 배정합니다.
- 리그 팀 구성은 2025/26 시즌 기준 샘플입니다.
