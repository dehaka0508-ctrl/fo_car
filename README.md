# 축구 커리어 시뮬레이터 (fo_car)

16세 유망주로 시작해 은퇴까지 개인 커리어를 이어가는 웹 기반 축구 시뮬레이션 게임입니다.

- **1단계**: 데이터 스키마, OVR 산출, 턴 시뮬레이션 코어
- **2단계**: 턴 사이 진행(훈련·상점·사건), 이적·오퍼·경쟁 선수, 시즌 결산(시상·승강·기록·레전드·파트너·라이벌).
  브라우저에서 **16세 데뷔부터 은퇴까지 클릭만으로 플레이할 수 있습니다.**
- **3단계 (현재)**: 득점·발롱도르 밸런스 재조정(포지션별 수상 가능성), 외부 구단 DB 자동 병합 파이프라인과 47개 리그 슬롯,
  바둑돌 하이라이트 연출(패스 궤적·골망·태클·선방), 상황별 아바타 의상(국가대표 유니폼·시상식 턱시도+트로피),
  커뮤니티 공유용 커리어 요약·텍스트 복사.

## 실행

```bash
npm ci            # 의존성 설치
npm run dev       # http://localhost:3000 → 커리어 게임 / http://localhost:3000/sandbox → 엔진 샌드박스 + 구단 DB 현황
npm test          # Vitest (133개)
npm run db:sync   # data/external/ 외부 구단 JSON 색인 갱신 + 병합 보고서 (dev·build·test·sim 전에 자동 실행)
npm run sim       # 시즌 단위 밸런스 점검 (SEEDS=100 npm run sim)
npm run sim:career  # 16세~은퇴 풀 커리어 자동 시뮬레이션 (CAREERS=30 ONLY=poacher,stopper DETAIL=0)
npm run sim:ballon  # 발롱도르 점수 보정표 (기준 시즌별 1위·포디움 확률)
npm run typecheck && npm run lint
```

> npm 10.9에서 `npm install <패키지>` 시 `Cannot read properties of null (reading 'edgesOut')` 오류가 나면
> `--legacy-peer-deps`를 붙여 설치하세요 (npm 자체 버그). `npm ci`는 영향이 없습니다.

기술 스택: Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS 4 · Zustand 5 (LocalStorage 세이브) · Vitest

## 플레이 방법

1. **캐릭터 생성**: 이름·국적·포지션·플레이스타일·키·몸무게·외형(피부·머리·눈동자)·시작 구단을 고릅니다.
2. **턴 사이** (탭 메뉴)
   - **훈련**: 카테고리 1개 또는 세부 능력치 2~3개, 또는 벌크업·감량. 강도(가볍게/보통/강하게)나 휴식을 고릅니다. 턴당 1회.
   - **상점**: 세부 능력치 1개를 올리는 아이템 1개 구매 (31세부터는 노화 방어). 턴당 1회.
   - **사건**: 턴마다 1~3개. 선택지마다 능력치·멘탈·명성·자산·체력이 달라집니다.
   - **이적**: 받은 오퍼(완전 이적·임대·재계약)를 수락하거나 거절합니다. 원하는 구단에 역제의(턴당 3회)하거나 재계약을 요청할 수 있고, 오퍼마다 그 팀의 경쟁 선수가 표시됩니다.
3. **턴 진행**: 전반기·후반기·프리시즌 중 한 턴을 시뮬레이션합니다. 하이라이트 경기에서는 바둑돌 피치 위의 상황마다 선택지를 고릅니다(성공률 표시). "AI에게 맡기기"로 건너뛸 수도 있습니다.
4. **결산**: 리그 시상식(후반기 후)과 세계 시상식(프리시즌 후)은 모달로, 기록 경신·레전드 헌액·이적·승격 같은 소식은 팝업으로 뜹니다.
5. **은퇴**: 30세부터 직접 은퇴할 수 있고, 40세가 되거나 33세 이상에서 FA로 6턴을 보내면 자동으로 은퇴합니다. 은퇴하면 커리어 요약 화면이 나옵니다.
6. **공유**: 은퇴 화면과 기록실 탭의 "커리어 요약 · 공유" 카드에서 시즌별 기록을 한눈에 보고, **클립보드에 텍스트 복사**로 커뮤니티에 붙여 넣을 수 있습니다.

"자동 1턴"과 "자동 1시즌" 버튼은 AI가 훈련·구매·사건·이적을 대신 결정해 진행합니다.
진행 상황(하이라이트 도중 포함)은 LocalStorage에 자동 저장되어, 새로고침해도 이어서 플레이할 수 있습니다.

## 커리어 루프

```
createCareer
  └─▶ READY (턴 사이: 훈련 · 상점 · 사건 · 이적)
        └─ startTurn ─▶ (하이라이트 대기) ─ continueTurn(바둑돌 결과) ─▶ completeTurn
              1. 턴 결과 반영: 입지 · 연봉 · 경기 경험 성장 · 통산 기록 · 파트너/라이벌 관계
              2. A매치 기간 (국가대표 차출 시)
              3. 기록 경신 판정 → 팝업
              4. 파트너 · 라이벌 생성/이탈
              5. 후반기 뒤 → closeLeagueSeason  (리그 시상 · 승강 · 구단 실력/명성/재정 갱신)
                 프리시즌 뒤 → closeSeasonCycle (세계 시상 · 시즌 기록 · 노화 · 경쟁 선수 순환 · 다음 시즌)
              6. 오퍼 생성 → beginInterTurn (회복 · 사건 1~3개) ─▶ READY
  ... 반복 ... ─▶ retire ─▶ RETIRED (커리어 요약 · 레전드 헌액)
```

- 연 3턴, 추춘제: `2026/27 전반기 → 후반기 → 프리시즌(대표팀 여름 대회) → 2027/28 전반기 …`
- 계약은 마지막 시즌 후반기가 끝나고 프리시즌에 들어갈 때 만료됩니다. 만료 전 턴에는 재계약 오퍼가 오고, 만료되면 FA로 최대 5개의 오퍼를 받습니다.
- 모든 무작위성은 `(시드, 대상 id, 용도)`로 나눈 독립 난수 스트림을 씁니다. 같은 세이브에서 같은 선택을 하면 결과가 같습니다.

## 2단계 규칙 요약

### 턴 사이 진행 (`engine/interTurn.ts` · `growth.ts` · `shop.ts` · `events.ts`)
| 항목 | 규칙 |
| --- | --- |
| 자연 회복 | 겨울 휴식기 +15, 시즌 종료 후 +20, 개막 전 +25 |
| 카테고리 훈련 | 6대 영역 중 1개 → 그 영역의 세부 3개 각각 기대 +1.15 |
| 세부 훈련 | 2개 고르면 개당 +2.1, 3개면 개당 +1.6 (집중할수록 크게) |
| 벌크업 / 감량 | 몸무게 ±(1.0~2.6kg). 벌크업은 몸싸움·공중볼↑ 가속·민첩↓, 감량은 그 반대 (BMI가 극단이면 체력 −0.5) |
| 강도 | 가볍게 ×0.6 (체력 −6) / 보통 ×1.0 (−12) / 강하게 ×1.4 (−20, 멘탈 −2), 휴식은 체력 +22 · 멘탈 +3 |
| 효율 보정 | 나이(18세 1.0 → 30세 0.25 → 34세 0.05) × 현재 수치(높을수록 덜 오름) × 확률적 반올림 |
| 상점 | 턴당 1개 · 세부 능력치 1개. **효과 = min(나이 보정 효과, 같은 능력치를 그 턴에 훈련했을 때의 기대 상승)** → 최고가 아이템도 훈련 1회를 넘지 않음. 20세까지 100%, 이후 나이에 반비례 |
| 노화 방어 | 31세부터 아이템은 상승 대신 "다음 시즌 노화 감소를 막는 방어막"이 됨 |
| 노화 | 30세부터 속도 → 지구력 → 힘·기술 → 판단형 능력치(결정력·시야·수비 위치 등) 순으로 감소. GK는 3년 늦게 시작 |
| 사건 | 턴마다 1~3개 (확률 45/35/20%). 가정사 · 언론 · 훈련 방식 · 스폰서 · 팀 · 파트너 · 라이벌 |
| **체력 100 규칙** | 후반기 뒤 '휴가 계획' 사건에서 **휴식**을 고르고 **그해 여름 대표팀 차출이 없으면** → 다음 시즌을 체력 100으로 시작 (`seasonStartCondition`) |

### 이적 (`engine/transfer.ts`)
- **개수 먼저, 조건은 나중에**: 오퍼 수는 0/1/2/3개(확률 40/30/20/10%), FA는 최대 5개로 먼저 정합니다. 그다음 내 OVR·명성·나이와 구단의 실력·명성·재정·지역성으로 구단을 고르고 조건을 정합니다.
- **조건**: 연봉 = 25,000 × e^(재정 × 0.06) × 역할 계수 × 명성 계수. 사우디·MLS 같은 자본 리그는 ×1.5. 재계약은 `max(시장 목표치, min(현 연봉 × 1.05, 시장가 × 1.3))`. 이적료 = 시장 가치 × 역할 계수 × (0.6 + 0.2 × 남은 계약 연수(최대 2)).
- **유형**: 완전 이적 / 임대(23세 이하, 최소 로테이션 보장, 1시즌) / 재계약 (계약 마지막 시즌, 또는 요청 시)
- **역제의**: 턴당 3회. 구단·유형(이적/임대)·희망 출전 시간을 지정하면 구단의 관심도에 따라 수락 여부가 정해지고, 수락되면 오퍼 목록에 추가됩니다. 재계약 요청은 별도로 할 수 있습니다.
- **경쟁 선수**: 오퍼마다 그 팀의 같은 포지션 경쟁자 0~3명(이름·나이·OVR·입지)을 보여 줍니다. 경쟁자는 시즌마다 나이를 먹고 성장·노화하며, 이적·은퇴·신규 영입으로 바뀝니다.

### 시즌 결산 (`engine/seasonEnd.ts` · `awards.ts` · `records.ts` · `narrative.ts`)
- **리그 시상** (후반기 후): 득점왕 · 도움왕 · MVP · 베스트 11 (포지션 부문)
- **세계 시상** (프리시즌 후): 발롱도르(30위까지 순위) · FIFA 올해의 선수(3위까지) · 월드 베스트 11 · 대륙 올해의 선수 · 국가 올해의 선수.
  리그 수준에 따른 인지도 보정(`leagueRecognition`)이 들어가 약한 리그에서 발롱도르를 받기는 어렵습니다. 점수 공식은 아래 '3단계 변경 요약' 참고.
- **승강**: EPL↔챔피언십 3팀, 라리가↔라리가2 3팀, K리그1↔K리그2 1팀 (B팀은 승격 불가)
- **구단 수치**: 성적이 기대 순위보다 좋으면 명성이 오르고, 우승 +2.5, 승격 +3, 강등 −6입니다. 실력은 `50 + 명성×0.4 + (재정−명성)×0.08`을 향해 매년 최대 ±2씩 움직입니다.
- **기록 경신**: 구단·리그·국가대표 통산 득점/도움/출전 기록을 넘으면, 기존 보유자 이름이 담긴 팝업이 뜹니다 (`data/legends.ts`의 `HISTORIC_RECORDS`).
- **레전드 헌액**: 한 구단에서 오래 뛰며 큰 기록을 남기고 떠나거나 은퇴하면 헌액됩니다. 같은 포지션의 실존 레전드가 데이터에 있으면 언급하고, 없으면 생략합니다.
- **파트너 · 라이벌**: 주전으로 3턴 이상 뛰면 확률적으로 생깁니다. 파트너는 같은 팀의 호흡 맞는 동료(투톱·센터백 듀오 등), 라이벌은 더비 상대·우승 경쟁 팀·세계적 스타 중에서 나옵니다. 매 턴 결과 화면에 기록을 나란히 비교해 보여 주고, 하이라이트에서 상대 팀에 있으면 이름표로 표시합니다.

## 3단계 변경 요약

### 득점 밸런스 (`engine/simulator.ts` · `data/playstyles.ts`)
- 득점·도움 점유율 상한을 **완만하게 눌러 주는 방식**(`softCap`)으로 바꿨습니다. 상한의 60%까지는 그대로, 그 위는 상한에 점점 가까워지기만 합니다.
- **득점 상한은 팀 수준에 따라 오릅니다**: 팀 실력 70 이하 0.27 → 90 이상 0.37. 빅클럽 에이스는 시즌 30~45골을 넣고,
  약팀에서 혼자 몰아치는 기록은 덜 부풀려집니다.
- 스타일별 기본 점유율을 낮췄습니다(포처 0.30→0.25, 플레이메이커 도움 0.24→0.16, 스토퍼 득점 0.035→0.017 등).
- **키패스** 기록을 새로 집계합니다(기대 도움 ÷ 전환율 0.16). 도움이 되지 않은 키패스는 평점(+0.1)과 명성에 반영되고, 미드필더 시상 평가에 쓰입니다.
- **미드필더 평점 보정**: 골·클린시트 보너스가 없는 미드필더가 공격수·수비수보다 평점이 체계적으로 낮았습니다(정상급 6.9~7.1).
  팀 수준을 웃도는 미드필더는 경기 장악(관여도)이 평점에 1.7배 반영되어 정상급이 7.2~7.4가 됩니다.
- **스타일 간 성장 속도 보정** (`engine/growth.ts`): OVR 가중치가 여러 능력치에 퍼진 스타일(박스 투 박스·인사이드 포워드)은
  같은 훈련으로도 OVR이 덜 올라 최고 OVR이 5~7 낮았습니다. 훈련 효율(상위 2개 가중치 비중 기준, 0.85~1.6배)과
  경험·자연 성장 배분을 정규화해 차이를 2~4로 줄였습니다(골키퍼는 노화가 늦어 조금 높습니다).

### 발롱도르 점수 (`engine/awards.ts` · `BALLON_CONFIG`)
```
점수 = 주전 기본점(50 × 출전 비율, 약한 리그는 최대 −30%)
     + 개인 성과 × 0.37 × 리그 인지도 × 포지션 보정
         개인 성과 = (평점 − 포지션 기준 평점) × 가중치 + 골·도움·키패스·클린시트
     + 국가대표 × 0.5
     + 우승 점수 × 포지션 가중치   (국내 리그·컵은 리그 수준만큼, UCL 14 · 월드컵 20 …,
                                    1부 리그 + 대륙 최상위 대회 더블 +6 × 대회 무게(UCL 1 · 리베르타도레스 0.7 · AFC 0.4))
     + 압도 보너스 (미드필더·수비수·골키퍼만): 최대치 × 압도 지수 × 성공도
         압도 지수 = 평점(포지션 기준 대비) 60% + 클린시트율(수비수·GK) 또는 경기당 키패스(미드필더) 40%
         성공도 = UCL 더블 1.0 · 월드컵 1.0 · 유로/코파 0.85 · 대륙컵만 0.5
     + 명성 × 0.15
```

## 유니폼 색 스키마 (`kitColors`) — 외부 구단 DB 연동용

```ts
// types/game.ts
export interface KitColors {
  primary: string;           // CSS 색 (예: '#DA291C')
  secondary: string | null;  // null → 단색, 값이 있으면 1-2-1-2-1 세로 줄무늬
}
ClubDefinition.kitColors: KitColors        // 필수
NationDefinition.kitColors?: KitColors     // 선택 (없으면 기본색)
```

- `components/Avatar.tsx`의 유니폼은 `secondary`가 있으면 `primary · secondary · primary · secondary · primary` 5등분 세로 줄무늬로 그립니다.
- `data/clubs.ts`의 행 형식은 `[id, name, nameKo, shortName, power, prestige, finance, primary, secondary|null, rivals, options?]`이고, `defineLeague`가 `kitColors: { primary, secondary }`로 바꿔 줍니다.
- 외부 JSON은 `kitColors: { primary, secondary }`(또는 `colors: [p, s]`, `primaryColor`/`secondaryColor`)로 넣으면 되고, 빈 `secondary`는 로더가 `null`로 바꿉니다.
- 가로 줄무늬·하프 유니폼(예: QPR, 그라나다)은 지금은 대표색 단색으로 근사합니다.

## 핵심 설계

### 1. 정적 데이터와 동적 상태의 분리
`data/`의 `*Definition`은 변하지 않는 원본입니다. 시즌마다 변하는 구단 실력·명성·재정·소속 리그·스쿼드(경쟁 선수)는
`ClubState`로 `GameState`에만 저장합니다. 세이브 크기를 줄이고 데이터 패치를 쉽게 하기 위함입니다.

### 2. 능력치와 시뮬레이션 결과의 분리 원칙
| 결과 | 사용하는 값 | 함수 |
| --- | --- | --- |
| 팀 성적 (스코어·승무패) | 팀 실력, **내 OVR × 멘탈 계수** | `effectiveTeamPower` → `expectedGoals` → `simulateScore` |
| 개인 기록 (골·도움·클린시트·평점) | **세부 능력치 분배**, 멘탈 | `goalShare` · `assistShare` · `calculateMatchRating` |

경기마다 `(시드, 경기 id, 용도)`로 독립 난수 스트림을 만들기 때문에, OVR이 같은 두 선수는 결정력·시야 분배가
달라도 **팀 결과가 완전히 같고 개인 기록만 다릅니다** (`tests/simulator.test.ts`에서 검증).

### 3. 체력과 출전 경기 수
경기마다 체력이 소모되고 휴식일만큼 회복됩니다. 체력이 55 아래로 떨어지면 감독이 로테이션을 돌려
선발 확률이 줄어듭니다(큰 경기는 예외). 리그 강도·대륙 대회 주중 경기·포지션·지구력이 모두 반영되어,
**OVR이 높아도 지구력이 부족하면 시즌 전 경기를 소화하지 못합니다.**

### 4. 턴 세션과 하이라이트 경기
- 세션은 순수 데이터라 하이라이트 대기 중에도 LocalStorage에 저장·복원됩니다.
- 하이라이트 경기는 턴을 선택지 없이 한 번 미리 돌려 본 뒤 규칙에 맞게 고릅니다.
  - 전반기: 라이벌 더비 (없으면 빅매치) / 후반기: 대륙컵 결승 > 국내컵 결승 > 후반기 더비
  - 프리시즌: 대표팀이 치른 마지막 국제대회 경기 > 연습경기 / B팀·유스: 리저브 더비
- 바둑돌 피치에서 상황(슈팅·키패스·드리블·수비·선방·세트피스)마다 선택지 3개가 나옵니다.
  성공률 = 시그모이드((선택지 핵심 능력치 − 상황 난이도)/12) × 멘탈 보정 (5~95%).
  결과는 득실점·골·도움·평점·멘탈로 바뀌고, 남은 경기에도 영향을 줍니다.

## 핵심 수식 요약 (`engine/simulator.ts` · `SIM_CONFIG`)

| 항목 | 수식 |
| --- | --- |
| OVR | Σ(스탯 × 가중치) / Σ가중치 — 플레이스타일별 `ovrWeights` |
| 멘탈 계수 | 0.9 + 0.2 × 멘탈/100 |
| 주인공 출전 시 팀 실력 | 구단 실력 + 0.12 × (OVR × 멘탈 계수 − 구단 실력) × 출전 비율 (GK 0.10) |
| 기대 득점 | 1.35 × e^(0.045 × (내 실력 + 홈 2.5 + 컨디션 노이즈 − 상대 실력)) → 포아송 |
| 득점 점유율 | softCap(스타일 기본값 × clamp(e^((득점 프로필 − 팀 수준)/22), 0.3, 1.8) × 멘탈 보정, 상한) · 상한 = 0.27 + 0.10 × (팀 실력 70→90) |
| 키패스 | 도움 + 포아송(기대 도움 × (1/0.16 − 1)) |
| 평점 | 6.45 + 관여도 + 골·도움 + 팀 결과 + 수비 기여(클린시트·실점·선방) + 멘탈 + 노이즈 |
| 체력 소모(90분) | 7 × 리그 강도 × 포지션·스타일 배율 × (1.4 − 0.7 × 지구력/100) |
| 체력 회복(1일) | 0.45 + 0.6 × 지구력/100 |
| 초기 능력치 | 기본 34 + 스타일 가중치 비례 최대 +24 + 키·BMI 보정 + 노이즈 (16세 OVR ≈ 50~55) |
| 시작 입지 | OVR − 팀 실력 ≥ −3 → 1군 / ≥ −12 → B팀 / 그 외 → U19 |

## 단순화한 부분 · 알려진 한계
- 토너먼트는 단판, 대륙 대회 조별리그는 4팀 더블 라운드로빈으로 근사합니다.
- 대륙 대회·국내컵 상대가 데이터에 부족하면 가상 팀(하부리그·대륙 클럽)으로 채웁니다.
- 리그 슬롯은 47개지만 구단 데이터는 아직 내장 샘플 8개 리그(2025/26 기준)뿐입니다. `data/external/`에 외부 DB를 넣으면 나머지 리그가 활성화됩니다.
  잉글랜드 3~4부처럼 슬롯에 없는 하부 리그는 국내 컵의 가상 하부 팀으로만 존재합니다.
- 자동 진행 AI의 미드필더 커리어는 최고 OVR 82~86에서 멈추는 경우가 많아, UCL 우승권 구단에 자리 잡지 못하고 포디움 근처(3~8위)에 머뭅니다.
  시상 공식 자체는 UCL 더블을 이끈 플레이메이커에게 1위 53%를 주도록 보정되어 있습니다.
- NPC 경쟁 선수·시상 후보는 이름·나이·OVR·포지션만 가진 가벼운 모델입니다(세부 능력치 없음).
- 세이브 버전이 바뀌면(`SAVE_VERSION`) 이전 세이브는 초기화됩니다. 키패스 도입 전 세이브는 그대로 이어서 플레이할 수 있습니다(키패스 0부터 집계).
